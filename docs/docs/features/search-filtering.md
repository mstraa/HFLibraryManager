# Search & Filtering

HF Library Manager provides powerful search and filtering to find projects quickly across large libraries.

## Full-Text Search

Powered by SQLite FTS5, search across project names and descriptions. Type in the search bar or press `Cmd/Ctrl + F` to focus it.

## Filters

### Tag Filters
- Click a tag in the sidebar to filter by it (include)
- Right-click a tag to exclude projects with that tag
- Multiple tags can be combined

### Collection Filters
- Click a collection in the sidebar to view only its projects

### Filament Filters
- Filter by specific filaments used in projects
- Include or exclude filaments
- **No filament** filter — Find projects without any filament data

### Ownership Filter
- **Owned** — Show projects where at least one filament is in your collection
- **Strict** — Show projects where all filaments are owned

### Size Filters
- Filter projects by print dimensions category

## Sorting

Sort projects by:
- **Name** — Alphabetical (A-Z or Z-A)
- **Created** — By creation date (newest or oldest first)
- **Modified** — By last modification date

## Clear All

One-click button to reset all active filters and search queries.
