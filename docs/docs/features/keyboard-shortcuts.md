# Keyboard Shortcuts

## Global Shortcuts

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + N` | Create new project |
| `Cmd/Ctrl + F` | Focus search bar |
| `Cmd/Ctrl + A` | Select all projects |
| `Escape` | Clear selection / close dialog |

## Navigation

| Input | Action |
|-------|--------|
| Mouse back button | Navigate back |
| Mouse forward button | Navigate forward |
| Trackpad swipe left | Navigate back |
| Trackpad swipe right | Navigate forward |

## File List

| Action | Interaction |
|--------|------------|
| Preview file | Click on an image or text file |
| Close preview | Click the X or click the same file again |
| Favorite/unfavorite | Click the star icon |
| Drag to external app | Click and drag a file (5px threshold) |
| Context menu | Right-click on a file |
