# Views

HF Library Manager offers multiple ways to browse and interact with your projects.

## Grid View

Visual cards showing:
- Project thumbnail
- Project name
- Tags as colored pills
- Filament color swatches
- File count, print size, and modification date
- Print icon for projects with 3MF files

## Table View

Compact tabular listing with:
- Sortable columns
- Thumbnail, name, tags, file count, size, and dates
- Efficient for browsing large libraries

## Thumbnail Modes

Control how project thumbnails are displayed:
- **Cover** — Crop to fill the card area
- **Contain** — Show the full image with letterboxing
- **Full** — Scale down to fit without cropping

## Multi-Select

- `Cmd/Ctrl + Click` to select multiple projects
- Selected projects enable the **Bulk Actions** toolbar:
  - Add tags to all selected
  - Add to collection
  - Delete selected

## Dark Mode

Full dark theme support that follows your system preference. The entire UI adapts including cards, sidebar, dialogs, and the file preview panel.
