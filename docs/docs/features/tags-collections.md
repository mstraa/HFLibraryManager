# Tags & Collections

Organize your projects with tags and collections for flexible categorization.

## Tags

Tags are colored labels you can assign to projects:
- **10 preset colors** to choose from
- **Unlimited tags** per project
- **Project counts** shown next to each tag in the sidebar
- **Inline creation** — Create new tags directly from the project detail view
- **Bulk assignment** — Add tags to multiple selected projects at once

### Using Tags for Filtering

- Click a tag in the sidebar to show only projects with that tag
- Right-click a tag to exclude projects with it
- Combine multiple tag filters

## Collections

Collections let you group related projects together:
- **Name and description** for each collection
- **Project counts** displayed in the sidebar
- **Inline creation** from the project detail view
- **Bulk assignment** across multiple selected projects

### Differences from Tags

| Feature | Tags | Collections |
|---------|------|------------|
| Purpose | Categorization | Grouping |
| Colors | 10 preset colors | No color |
| Description | No | Yes |
| Filtering | Include/exclude | View only |
